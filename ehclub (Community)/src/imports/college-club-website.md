Design a clean, modern, professional website for a college technical club.

Overall style:
– Minimal design with white background and blue accent color
– Professional sans-serif typography
– Responsive layout for desktop and mobile
– Elegant, formal look suitable for an official club website

Header / Navigation:
– Fixed top navigation bar
– Left side: circular club logo
– Right side menu items:
  Home | About | Projects | Events | Members | Contact
– Highlight active menu item with a blue underline

Home Page:
– Large bold club name as the main focus
– Professional tagline below the club name
– High-quality professional technology-themed image
– Clean hero section layout that looks modern and inspiring

About Page:
– Vision and Mission displayed in two separate cards
– Club statistics section showing:
  Number of events conducted
  Number of members
  Years active
– Inauguration section with:
  Photo gallery (3–4 images)
  Short description about the inauguration event

Events Page:
– Grid of event cards
– Each event card includes:
  Event poster image
  Event name
  Date
  Time
  Venue
– For past events:
  Add a “Winners” button that opens a popup showing winners
– For upcoming events:
  Add a “Register” button that opens an external Google Form link

Members Page:
– Display total count of office bearers and total members
– Highlight President and Vice President with larger cards
– Show office bearers in a clean grid layout
– Each member card includes photo, name, and designation

Contact Page:
– Display contact details:
  Phone number
  Email address
  LinkedIn icon with link
  Instagram icon with link
– Contact form with fields:
  Name
  Email
  Message
– Submit button
– Indicate that messages will be received to the club email

Design should be simple, professional, well-aligned, and visually balanced.
